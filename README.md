# flattenthecurve

Go back to the COVID days where we were all locked in our house. We were told to keep social distancing to flatten the curve and avoid the peak. 
 
This Jupyter note book provides a simple setup to study the effect of social distancing and contamination rate on flattening the curve. Change the number and rerun to see how it works. 

The model is based on massive assumptions and should be used exclusively for learning purpose.

While COVID-19 is now behind us and none of use would desire anything close to happen again, its good to understand some phenomenon computationally.
